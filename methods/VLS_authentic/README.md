# VLS_authentic — VLS (arXiv:2602.03973) 충실 구현

VLS(vanilla)와 같은 논문이되, 단순화했던 부분을 **Algorithm 1 그대로** 되돌린
판이다. 대체하는 것은 **지각 스택 하나뿐**이다:

    SAM + DINOv2 + 깊이 → 3D 키포인트 P   ⟹   시뮬 특권 상태(좌표 + 요)

## VLS(vanilla) 와의 차이 — 유도가 일어나는 위치

| 논문 구성요소 | VLS(vanilla) | VLS_authentic |
|---|---|---|
| 입자 초기화 | 독립 노이즈 K개 | 독립 노이즈 B개 + **RBF 반발**(eq.8) |
| 보상 기울기 주입 | 완성된 표본에 사후 정제 | **디노이징 스텝마다**(Alg.1 14-16) |
| MCMC 내부 갱신 | 없음 | 스텝당 m=4회 |
| 리샘플링 | argmax 선택 | **Feynman-Kac 가중**(eq.9) |
| 적응형 강도 λ | 있음(eq.10) | 있음(eq.10) |
| 스테이지 전환 | done 술어 | **Schmitt 트리거**(eq.11) + done, 이력 2회 |

디노이징 루프 내부 접근이 필요해 서버에 `/act_chunk_guided` 를 두고, GR00T 의
`get_action_with_features` 를 호출 동안만 교체한다. 정책 가중치는 건드리지
않는다 (training-free).

## 구현에서 실측으로 잡은 것

**액션 패딩** — GR00T 는 다중 임베디먼트를 위해 액션을 132차원으로 패딩해
디노이징한다. 후처리가 앞 4차원만 잘라 쓰므로(`action[..., :env_action_dim]`)
유도도 같은 슬라이스에만 건다.

**정규화 아핀 역산** — 보상은 월드 좌표, 디노이징은 정규화 공간이다. 정규화
모드를 추측하는 대신 두 점(0, 1)을 후처리에 통과시켜 `world = norm*scale +
offset` 을 역산한다 (검증 오차 3e-8).

**변위 상한이 필수** — 상한 없이 λ·lr·MCMC 를 누적하면 정규화 액션 범위(±1)를
통째로 넘어 궤적이 정책 매니폴드 밖으로 날아간다 (실측: 파지 0회, λ 가 2.0 에
고정된 채 폭주).

## 유도 강도와 파지의 상충 (실측)

task3 에서 유도 변위 상한별 파지 성공 관측 수:

| 조향 끔 | 0.02 | 0.05 | 0.12 |
|---|---|---|---|
| 18 | 13 | 10 | 10 |

**어느 강도에서도 유도는 파지를 해친다.** 정밀 조작 구간에서 궤적을 cm 단위로
밀면 그리퍼가 캔을 빗나가기 때문이다. 파지가 가장 덜 깨지는 0.02 를 운영점으로
삼았다. 이는 VLS 계열이 task3 에서 기본 VLA 보다 낮은 SR 을 내는 근본 이유이며,
논문이 겨냥한 OOD 적응과 우리 태스크(정책이 이미 유능함)의 성격 차이를 보여준다.

## 실행

```
./run_eval.sh VLSa task3 50
./run_eval.sh VLSa            # 3태스크 × 50에피
# 진단
--guide-off        조향을 끄고 청크 실행 경로만 (원인 격리)
--max-dev 0.05     유도 변위 상한 스윕
```
