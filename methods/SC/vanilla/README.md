# SC — VLSA/AEGIS (arXiv:2512.11891) vanilla 구현

플러그앤플레이 안전 제약(SC) 층. vanilla abs VLA(task*_abs) 위에 학습 없이 얹는다.

## 논문 → 구현 대응

| 논문 구성요소 | 구현 (`sc_runner.py`) | 충실도 |
|---|---|---|
| VLM 의미 안전 평가 — 지시문+장면에서 가장 위험한 장애물 지목 | gemini-3.7-flash 가 front 카메라+물체 목록에서 장애물 이름 반환 (에피소드 시작 + task3 라운드 재배치 시) | **충실** |
| GroundingDINO + 깊이 융합 + 이상치 제거 + MVEE 타원체 피팅 | 시뮬 특권 상태(정확한 물체 자세) + 실측 치수 타원체 (worker_arm 캡슐→반축 0.335/0.075/0.075, 캔→0.05/0.05/0.06) | **대체** — 시뮬엔 지각 스택이 불필요, 논문의 "의미→기하→제약" 사슬은 유지 |
| EEF 타원체 + 부호 있는 거리 h | EEF 를 제어점+팽창(민코프스키 합)으로 장애물 타원체에 흡수한 레벨셋 h(p)=‖D⁻¹(p−c)‖²−1 | **단순화** — 논문 eq.9 의 보조 상태 최적화 대신 표준 팽창 타원체 CBF |
| CBF-QP: min‖u−u_vla‖² s.t. ḣ≥−αh (eq.2) | 제약이 u 에 선형이라 반공간 사영의 닫힌형 = QP 최적해. α=2.0, 6Hz | **충실** |
| 위반 없을 때 원 액션 유지 | 제약 만족 시 u 그대로 통과 | **충실** |
